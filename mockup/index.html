3310-eink

A Nokia 3310-style checklist and clock for the M5Stack CoreInk e-paper display. ESPHome runs the device, Home Assistant manages the tasks. Try it below: the screen is drawn from the same pixel coordinates as the firmware.

    This is a browser preview, not a photo of the running device. Text uses browser fonts with the firmware's line metrics, so widths differ slightly. The firmware is experimental; validate it with ESPHome before flashing.

    One list per daypartMorning, midday and evening each get up to five tasks. The device wakes at each start and resets that list once a day.
    Managed in Home AssistantTasks live in normal HA to-do lists: add, rename and tick them from the dashboard, the app or by voice.
    Sleeps between daypartsDeep sleep saves the battery. The side button wakes it any time, and the last image stays on the e-paper.
    Done stays doneA finished list is locked, so nothing gets unticked by accident. German or English, switched in HA.
    Experimental: both firmware files compile with ESPHome 2026.10 but are not yet tested on hardware. MIT licensed. Read the full README. Like it? Support the project on Ko-fi or Buy Me a Coffee.
