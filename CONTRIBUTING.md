# Contributing

1. Make a backup before testing changes on physical hardware.
2. Never commit secrets, broker passwords, Wi-Fi credentials or API keys.
3. Validate Home Assistant configuration and run ESPHome validation before flashing.
4. Include ESPHome and Home Assistant versions in bug reports.
5. Describe whether a report is about display rendering, buttons, wake/sleep, MQTT sync, HA entities or battery readings.
6. Redact logs before sharing them publicly.
